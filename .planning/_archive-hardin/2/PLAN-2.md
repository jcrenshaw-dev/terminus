# Phase 2: Redaction - Plan 2

## Goal

With `[privacy] redact_recall` on, a secret stored as a string under a secret-named key in a `tool_use` input, a `toolUseResult` or an attachment is replaced in the `recall_search` excerpt, the `recall_context` text, the brief and the per-prompt injection, the way `recall_get` already replaces it (#62). The egress test proves each planted shape is replaced by its own rule's marker in the turn that holds it (#4). A new rooted fixture carries this phase's shapes.

## Must be true when done

- `session-redaction.jsonl` is a rooted fixture under `project-epsilon`, and every existing test passes with it in the corpus, the recall golden included.
- With the knob on, each of the fixture's three keyed secrets is gone from its turn's `recall_search` excerpt and `recall_context` text, `[redacted]` stands where it was, and no key name is added to the text. `recall_get` still replaces it. The `tool_use` one is gone from the per-prompt injection. With the knob off, each comes back whole.
- A record with no secret-keyed string value projects byte-identically with the knob on and off. That includes a record whose secret-named key holds a number, a list of strings, or an object with no secret-named key inside.
- The egress test checks every planted shape of both fixtures in the turn that holds it, in the `recall_context` window and in the `recall_get` body. Taking out any one of the nine rules, or the keyed-value step, makes it fail on that shape's turn.

## Context

- Locked: D-01 (the keyed step runs on the egress side over the parsed record, before `text::project`, only with the knob on; `text::project` and the FTS body do not change), D-02 (rule 4's own test at every depth the projection walks; strings only; secret-named keys nested inside a non-string value are still caught), D-03 (no key names in the excerpt; replaced where it stands; byte-identical otherwise), D-05 (one fix in `excerpt::of_record_scrubbed`; `recall_get` stays on `apply_json_line`), D-06 (the injected-text test uses a `tool_use` with a `PATH_INPUTS` key), D-04 (per-turn check; rules 3 to 5 keep sharing `REDACTED`), D-13 (a new rooted fixture under its own project key; `session-secrets.jsonl`, the golden and the brief's Cookie tests stay as they are).
- Pattern: `session-secrets.jsonl` with `project-delta` and `session-envelope.jsonl` with `project-gamma` are how a rooted fixture joins. `tests/redacted_recall.rs`'s `bench`, `Bench::config` and `injected`, and `tests/egress.rs`'s `read_both_ways`, `projected` and `got`, are the harnesses to extend.
- Out of this plan: `index::text`, `recall::get`'s key test, the markers of rules 3 to 5, curly quotes, the boundary tests and the user docs.
