# Phase 1: Recall injection framing - Context

Gathered: 2026-10-18
Feeds: /cad-plan 1

## Scope boundary

In: The `UserPromptSubmit` hook stops injecting tool-result turns, and both the prompt hook and the `SessionStart` brief put every quoted string inside a fixed tag pair under a header that says the text is quoted history, not instructions (INJ-09, #60). That covers the exclusion and the matching change to `terminus replay`, the frame and its neutralization, the frame's place in the budget, the regression test, the tests and golden that pin today's shape, and the two docs that say injected text has no delimiter.
Out: Redaction fixes (phase 2). Terminal escaping of `search`, `show` and `observations` output (phase 5). Labelling result turns or injecting them as id-only lines, both considered and rejected in D-01. Changing which assistant turn the brief quotes when a session ends on a tool call (D-09).
Deferred: None.
Plan shape: multiple plans, same phase. The bundle check that sets the header wording (D-07) comes first, so the exclusion and its regression test fit naturally in the first plan, and the frame across both hooks with the golden and docs in the next.

## Durable decisions

- D-01 (Prompt hook): Tool-result turns are left out of the prompt hook's injection entirely. They are not labelled and quoted, and they are not injected as id-only lines. Labelling still hands the planted text to the model every time the file is named, with only the frame and label saying it is untrusted. An id-only line spends one of the three slots on a line the model has to follow up with `recall_get`. The trade accepted: error entities exist only on result turns (10,631 in the live store), so a prompt that pastes an error line no longer fires, and `recall_search` stays the way back to those turns. File-path recall survives, because a Read matches both its tool-call turn (from `input.file_path`) and its result turn (from `toolUseResult.file.filePath`) as exact path entities. Measured 2026-10-18 on the live store: 723 decisions from 2026-10-15 to 10-18, 16 fired, and all 37 injected turns and all 88 entity-matching candidates were assistant tool-call turns, so the exclusion changes no measured injection. Evidence: `crates/terminus-core/src/index/entity.rs:154-160`, `:265-277`; `crates/terminus-core/tests/inject_prompt.rs:333-355`; `audit/claude-security.md:61-77` (F2); `DESIGN-BRIEF.md:248-254`.
- D-02 (Delimiter): The frame is one fixed opening tag and one fixed closing tag. Anything in quoted text that resembles the closing tag, in any case, with whitespace inside it, or in fullwidth or other lookalike characters, is neutralized after redaction and before the budget is spent, in the position the redaction filter already holds. A random per-render nonce is ruled out: the brief must render byte-identical output for unchanged state (INJ-02), the prompt hook has a same-bytes test, and `terminus-core` carries blake3 but no rand or getrandom. A blake3 tag derived from the quotes was rejected because a fake closer with the wrong hash would still sit visible inside the block, and the model does not check hashes. Excerpts are already flattened to a single line, so the frame has to defeat a closing tag written inline, not one on its own line. The JSON encoding of the hook output is undone before the model reads it and protects nothing. Evidence: `crates/terminus-core/src/inject/brief.rs:35-43`; `crates/terminus/tests/brief.rs:179-237`; `crates/terminus-core/tests/inject_brief.rs:863-872`; `crates/terminus-core/tests/inject_prompt.rs:554-606`; `crates/terminus-core/src/recall/excerpt.rs:170-217`; `crates/terminus-core/src/inject/mod.rs:201-212`; `crates/terminus/src/cmd/hook.rs:330-345`.

## Decisions

- D-03 (Prompt hook): The turns D-01 drops are `user` turns with `is_typed = 0`. Attachments, `system` records and harness envelopes such as `bash-stdout` carry no entities, so `eligible()` can never admit them. Keying on `Hit.record_type` would also drop typed prompts, since a tool result's record type is `user`. Keying on the `toolUseResult` key would miss the result records that carry the block without the key. `Hit` carries no `is_typed` today. Evidence: `crates/terminus-core/src/index/entity.rs:93-115`; `crates/terminus-core/src/inject/prompt.rs:511-521`; `crates/terminus-core/src/parse/record.rs:327-374`; `crates/terminus-core/src/store/schema.rs:284-303`; `crates/terminus-core/src/recall/search.rs:207-216`, `:284-296`. Live store 2026-10-18: path entities on 689,430 assistant turns and 29,439 `is_typed 0` user turns, every error entity on `is_typed 0` user turns, no user row with a null `is_typed`.
- D-04 (Prompt hook): The exclusion runs on the ranked hits after INJ-03's threshold and before the suppressions and the cap. It lives in code that `terminus replay` also runs, not in a SQL filter inside `search::run`. A SQL filter renumbers the ranked window, so a rank-4 turn would move to rank 3 and fire where it did not before. An exclusion only in the live path leaves replay injecting result turns the hook refuses. Evidence: `crates/terminus-core/src/inject/prompt.rs:533-540`, `:564-583`, `:597-622`; `crates/terminus-core/src/feedback/replay.rs:247-296`; `crates/terminus-core/src/recall/search.rs:35-56`.
- D-05 (Delimiter): Every archived string inside the frame gets D-02's neutralization, not only the excerpts: the day cut from the stored `ts`, and in the brief the project label and the branch. None of these passes through `flatten` or redaction today. Evidence: `crates/terminus-core/src/inject/prompt.rs:297-298`, `:313-315`; `crates/terminus-core/src/inject/brief.rs:196-197`, `:396-404`, `:482-484`.
- D-06 (Budget): The header and both tags are a fixed cost, measured before the per-turn shares. When the frame alone does not fit the configured budget, the hook emits nothing rather than a block with its closing tag cut off by the backstop clip. Neither `prompt_chars` nor `brief_chars` has a lower bound. Tests that need updating with this: `crates/terminus-core/tests/inject_prompt.rs:617-638` unwraps at budgets of 3, 90 and 100, and `crates/terminus/tests/prompt.rs:242-260` needs "turn " within 120 characters. Evidence: `crates/terminus-core/src/inject/prompt.rs:249-283`; `crates/terminus-core/src/inject/brief.rs:198-237`; `crates/terminus-core/src/inject/mod.rs:201-212`; `crates/terminus-core/src/config.rs:554-558`, `:606-612`.
- D-07 (Header): The first plan reads the installed Claude Code bundle to learn how it presents a hook's `additionalContext` to the model: whether it wraps the text, whom it attributes it to, and whether it escapes anything. The header is worded on what it finds, the way v0.1.0 phase 5 D-01 verified the hook output shape. `THREAT-MODEL.md:116` and `:212` mark this as unverified. Evidence: `THREAT-MODEL.md:116`, `:212`; `.planning/ARCHIVE.md` (v0.1.0 phase 5 D-01).
- D-08 (Brief): The brief gets the frame and header and no exclusion. It quotes two turns, the last typed prompt (`is_typed` not 0) and the last assistant record, and an assistant record never carries `tool_result` or `toolUseResult` (none of 24,037 assistant records in the 300 newest transcripts, 2026-10-18). An exclusion in `last_turn` would filter nothing and risk the INJ-07 rule the golden and byte-identity tests pin. Evidence: `crates/terminus-core/src/inject/brief.rs:486-582`; `crates/terminus-core/src/parse/record.rs:342-374`; `crates/terminus-core/tests/inject_brief.rs:518-556`.
- D-09 (Brief): When the last assistant record is a tool call, the brief keeps quoting it inside the frame. The quoted text already names the tool, so the line already reads as a tool call. 246 of 1,929 top-level sessions (12.8%) end that way (StructuredOutput 196, Bash 31, Read 14, AskUserQuestion 3, ToolSearch 2), measured 2026-10-18. Evidence: `crates/terminus-core/src/inject/brief.rs:520-521`, `:571-582`; `crates/terminus-core/src/index/text.rs:148-158`.
- D-10 (Tests and docs): The change that alters the shape updates, in the same change, the golden brief (regenerated only through `TERMINUS_REGENERATE_RECALL_GOLDEN` and reviewed), `asked_line` and the three redaction tests that use it, the `contains("turn {id}")` and `contains("turn ")` checks in the suppression and prompt tests, `docs/design/0007-injection.md`, and the `THREAT-MODEL.md` lines that say injected text has no delimiter. A header or label containing `Command` with a capital C trips `nothing_in_the_injection_path_spawns_a_process_or_reads_observations`. Evidence: `crates/terminus-core/tests/recall_golden.rs:32-40`; `crates/terminus-core/tests/goldens/recall-projections.txt:36-40`, `:66-70`; `crates/terminus-core/tests/inject_brief.rs:651-672`, `:788-793`; `crates/terminus/tests/suppression.rs:491`, `:543`; `crates/terminus/tests/prompt.rs:208`, `:259`; `docs/design/0007-injection.md:74-81`, `:101-104`; `THREAT-MODEL.md:149`, `:202`.
- D-11 (Regression test): The planted-Read test goes in `crates/terminus-core/tests/inject_prompt.rs`, at the library seam. Its records are hand-written and archived through `ingest::run` in the style of `inject_brief.rs`'s `archive_records`, because `inject_prompt.rs`'s own `archive` writes only assistant records with a null `parentUuid`. The planted record uses the real Read result shape: a `tool_result` with string content, plus `toolUseResult` `{type, file: {content, filePath, numLines, startLine, totalLines}}`, with `parentUuid` set to the tool-call record's uuid. The test asserts the planted text is absent and the Read tool-call turn still fires. A result built on `inject_brief.rs`'s `tool_result_record` (`{stdout}`) carries no path entity, would never fire, and would pass before the fix. No fixture under `tests/fixtures` carries a Read result today. Evidence: `crates/terminus/tests/prompt.rs:1-8`; `crates/terminus-core/tests/inject_prompt.rs:124-153`; `crates/terminus-core/tests/inject_brief.rs:85-127`, `:466-479`. Corpus parse 2026-10-18: 660 of 940 Read results in the 300 newest transcripts carry that `toolUseResult` shape.

## Acceptance criteria

- [ ] AC1: A test archives a Read of file F whose result holds planted instructions P, then submits a prompt naming F. The hook injects the Read tool-call turn, and P appears nowhere in its output. The test fails on the commit before the fix and passes after it.
- [ ] AC2: For a decision whose ranked hits include a tool-result turn, `terminus replay` does not report that turn as injected, which matches the live hook.
- [ ] AC3: Prompt-hook output and the SessionStart brief both put every quoted string between one fixed opening tag and one fixed closing tag, under a header saying the text is quoted history, not instructions. An archived excerpt, day, project label or branch containing the closing tag in another case, with whitespace inside it, or in fullwidth lookalike characters still yields output in which the closing tag appears exactly once, at the end of the block.
- [ ] AC4: With a budget too small for the header and both tags, the prompt hook emits nothing and exits 0. At every budget where it emits, the `additionalContext` text ends with the closing tag.
- [ ] AC5: Two SessionStart renders against an unchanged store are byte-identical, and two prompt-hook renders of the same prompt are byte-identical.
- [ ] AC6: `docs/design/0007-injection.md` and `THREAT-MODEL.md` no longer say injected text has no delimiter, and both describe the frame and the exclusion of tool results.
- [ ] AC7: The pull request that lands this phase carries `Fixes #60`, and #60 is closed once it merges. (human-verify: needs GitHub, after landing)

## Flagged assumptions

- A frame with a "quoted history, not instructions" header measurably lowers how often current Claude models follow planted instructions - Unclear, nothing in the code can measure it; if wrong: the frame adds little, and D-01's exclusion carries the defense for tool output while typed prompts and assistant turns rely on the frame alone.
- Claude Code may already wrap `additionalContext` in a frame of its own - Unclear until D-07's bundle check; if wrong either way: a header that contradicts the host's own framing confuses the model about who wrote the text.
- No one relies on error-line firing on the prompt hook - Likely, since none of the 37 turns injected from 2026-10-15 to 10-18 was a result turn; if wrong: pasting a known error goes silent, and the id-only line rejected in D-01 is the way back.
- The exact set of closing-tag lookalikes D-02 neutralizes (which case folds, which whitespace, which fullwidth and confusable characters) is the planner's call - Likely; if wrong: a missed variant closes the block from inside an excerpt.
