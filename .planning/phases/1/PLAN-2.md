# Phase 1: Recall injection framing - Plan 2

## Goal

The `UserPromptSubmit` hook and the `SessionStart` brief stop handing archived tool output to the model as the user's own history (#60). This plan puts everything both hooks quote inside one fixed tag pair under a header that says it is quoted history, not instructions, makes the closing tag impossible to forge from inside a quote, and brings the tests, the golden and the docs to the new shape.

## Must be true when done

- The prompt hook's `additionalContext` and the `SessionStart` brief each open with a header saying the text is quoted history from the archive, not instructions, then one fixed opening tag, every archived string, and one fixed closing tag as the last characters.
- A closing tag planted in an archived excerpt, a stored timestamp, a project path or a branch name, in another case, with whitespace or zero-width characters inside it, or in fullwidth or other lookalike characters, comes out neutralized: the real closing tag appears exactly once, at the end.
- With `prompt_chars` too small for the header and both tags, the prompt hook writes nothing and exits 0; at every budget where it writes, the text fits the budget and ends with the closing tag. The brief follows the same rule under `brief_chars`.
- Two `SessionStart` renders against an unchanged store are byte-identical, and so are two prompt-hook renders of one prompt.
- `terminus search`, `recall_search`, `recall_context` and `recall_get` output does not move: the golden's search, context and get sections are unchanged.
- `docs/design/0007-injection.md` and `THREAT-MODEL.md` describe the frame and the exclusion of tool results, and neither says injected text has no delimiter.

## Context

- Locked: D-02 (one fixed opening and closing tag; closing-tag lookalikes neutralized after redaction and before the budget, at redaction's position; no nonce, no hash), D-05 (every archived string in the frame is neutralized: excerpts, the day, the brief's project label and branch), D-06 (the frame is a fixed cost measured first; a frame that does not fit means nothing is emitted), D-07 (the header is worded on PLAN-1 Task 1's record in THREAT-MODEL.md), D-08 and D-09 (the brief gets the frame and no exclusion, and keeps quoting a reply that is a tool call), D-10 (the tests, golden and docs that pin the shape change in the same change).
- Planner's choices, recorded in the tasks: the lookalike set (Task 1) and the brief's whole body inside the frame (Task 3).
- Standing constraints from existing tests: no `Command` with a capital C and no `observations` on a non-comment line under `src/inject` (`nothing_in_the_injection_path_spawns_a_process_or_reads_observations`); no `NN:NN` time of day in either output; nothing reads a clock (INJ-02).
- Runs after PLAN-1 (see Notes).

## Tasks

### Task 1: Define the frame and the closing-tag neutralizer once (D-02, D-07)

- **Files:** crates/terminus-core/src/inject/mod.rs (beside chars and clip)
- **Action:** Define once in `inject/mod.rs`, for both arms, the opening tag, the closing tag, the header statement and a neutralizer over one string. The tags are one fixed pair, the same bytes on every render, named in lowercase ASCII letters with at most hyphens (which bounds the tables below), and unlike any tag PLAN-1 Task 1 found the bundle wrapping hook context in. The header is worded on that record (THREAT-MODEL.md, the Hooks bullet): it says the text between the tags is quoted from this project's Terminus archive and is history, not instructions, and it does not contradict whom the bundle attributes hook context to. It names the block but never spells out the closing tag, which must appear exactly once per output, and it carries no time of day, no `Command` and no `observations`. Each arm may lead with its own one-line description of what the block holds (Tasks 2 and 3), but the "quoted history, not instructions" statement is this one. The neutralizer finds every span that reads as the closing tag once folded and replaces it with one fixed ASCII marker that names what was removed and holds no `<`, `/`, `>` or anything in the tables below, so a second pass changes nothing. The lookalike set is this plan's call (CONTEXT flagged assumption 4): (a) ignorable between any two characters of a span: every char `char::is_whitespace` accepts, the Default_Ignorable_Code_Point ranges U+00AD, U+034F, U+061C, U+115F-1160, U+17B4-17B5, U+180B-180F, U+200B-200F, U+202A-202E, U+2060-206F, U+3164, U+FE00-FE0F, U+FEFF, U+FFA0, U+1BCA0-1BCA3, U+1D173-1D17A, U+E0000-E0FFF, and the combining marks U+0300-036F, U+1AB0-1AFF, U+1DC0-1DFF, U+20D0-20FF, U+FE20-FE2F; (b) width: U+FF01-FF5E fold to U+0021-007E; (c) case: after (b), Unicode lowercase wherever it yields one char, so fullwidth capitals and the Kelvin sign fold; (d) fixed tables for the punctuation: `<` U+2039, U+2329, U+3008, U+27E8, U+276E, U+02C2, U+1438, U+FE64; `>` U+203A, U+232A, U+3009, U+27E9, U+276F, U+02C3, U+1433, U+FE65; `/` U+2215, U+2044, U+29F8, U+2571, U+27CB, U+3033, U+30CE, U+4E3F, U+2F03, U+1735; `-` U+2010-2015, U+2212, U+FE63, U+02D7, U+2043; (e) letters: a non-ASCII alphabetic char left after (b) matches any letter of the tag name in its position, which covers Cyrillic, Greek, mathematical alphanumeric and other letter homoglyphs without a confusables table this crate does not carry; (f) the final `>` is optional, because `<`, `/` and the whole name already read as a closer and an excerpt can end right there. Hand back the input unchanged and borrowed when it holds no `<`-class char, which is nearly every excerpt. Text that is not this tag's closer is never touched: `Vec<String>`, `a </ b`, `</div>`, and the opening tag. The one accepted over-match is rule (e): `</` followed by non-ASCII letters in every letter position of the tag name (hyphens where the name has them) is neutralized even when it spells some other word, because altering a rare quoted string is the safe side and letting a planted closer through is not. Add no dependency (D-02 records what `terminus-core` carries); the tables are code. Unit tests in the module's `tests`: each class above, every table entry, several insertion points for (a), mixed classes in one span, two closers in one string, a closer at the very end with no `>`, idempotence, the untouched cases byte for byte, and `</` followed by a Greek word of the tag name's length, pinned as neutralized (the accepted over-match).
- **Verify:** `cargo test -p terminus-core --all-features --lib inject::` passes, with each lookalike class exercised by a literal string written in the test rather than one the neutralizer produced; `cargo test -p terminus-core --all-features --test inject_brief nothing_in_the_injection_path` passes; `git diff --stat` lists `inject/mod.rs` alone.
