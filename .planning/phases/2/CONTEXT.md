## Durable decisions

- D-01 (Guard test): In Rust comments, TOML comments and the SQL comments in `CREATE_SQL`, the guard fails on any token of 2 to 6 capitals, a hyphen and exactly two digits, with an allow-list for real names such as `UTF-16`. It also fails there on `D-NN`, `AC` followed by digits, `PLAN-N`, and "phase N" in any case. In markdown it fails on the same tag families but allows "phase N" as ordinary prose. The generic capitals rule catches this milestone's requirement ids (SHED, TAGS, GATE, SRCH, PASS, ARCV, OWN, OUT) and any later milestone's with no edit to the test, and it applies to everything phases 3 to 8 write: phase 1 added 4 lines with D-NN tags (`crates/terminus-core/src/store/open.rs`), so executors still write tags. Rejected: #106's twelve families only, and #106's families plus this milestone's eight. Evidence: #106, `.planning/REQUIREMENTS.md`, `.planning/ROADMAP.md:5`.
