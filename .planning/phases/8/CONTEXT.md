# Phase 8: Output - Context

Gathered: 2026-10-27
Feeds: /cad-plan 8

## Scope boundary

In: Every command's human output, on stdout and stderr, escapes control characters in archived text through one default path in the `terminus` binary, with an explicit raw path for `--json` documents, the hook document and `show <id>`'s record body (#72). `main` knows each command's output mode, and every `--json` command that fails operationally prints its own empty document with `ok: false` and the reason; `read::unusable` goes (#107). One byte formatter, one duration formatter, one `Failure`-to-text function and one home for the cleanup-day constants (#107). `uninstall --purge` shows and reports the size of everything it deletes (#95). The prompt line marks a turn it cut to a share of 3 characters or less (#94). The docs that describe these change with the code.
Out: What `--purge` deletes, and its no-`terminus.db` case (#95). `inject::clip` itself and the brief's behavior from #46 (#94). Escaping inside core, the store, `--json` values or the MCP results. Misuse (exit 2) writing a document. `mcp::serve`'s output.
Deferred: None.
Plan shape: multiple plans, same phase. Suggested order: the output mode carried into the dispatcher (which #72's raw path and #107's documents both need), then the escaping helpers and lint, then the `--json` failure documents, then the shared formatters and the purge size, then the prompt-line mark.

## Durable decisions

- D-01 (Escaping): The escape runs in the `terminus` binary where output is written. Core renderers (`verify::Report::render`, `pass::note`, doctor's `Check.finding`, the run row's `notes` and `error`), the store, `--json` values and the MCP results stay byte for byte. Escaping in core was rejected because it changes `--json`, the MCP recall results and the pinned recall golden. Evidence: `crates/terminus/src/escape.rs`, `crates/terminus-core/src/verify.rs` (`Report::render`), `crates/terminus-core/tests/recall_golden.rs`, `.planning/PROJECT.md` Key Decisions ("Redact at egress, never at ingest").
- D-02 (Escaping): `outln!` and `out!` in `out.rs` escape the whole formatted text by default. Output that must stay byte for byte takes an explicit raw call at its site: `Document::emit` and `try_emit`, the hook's `emit`, and `show`'s record body. A process-wide output-mode flag does not choose it, because the hook document and `show`'s body are not `--json` output. Rejected: an opt-in display wrapper per argument, which repeats the per-site failure #72 describes. Evidence: `crates/terminus/src/out.rs`, `crates/terminus/src/cmd/json.rs`, `crates/terminus/src/cmd/hook.rs:332-345`, `crates/terminus/src/cmd/show.rs:104-145`, `THREAT-MODEL.md:128`.
- D-03 (Escaping): A matching stderr helper escapes by default and replaces every `eprintln!` in `crates/terminus/src` (33 sites in 12 files), `main`'s `terminus: {msg}` included, and `clippy::print_stderr` is denied the way `clippy::print_stdout` is. John chose all of stderr with a lint over converting only the archived-text sites. Evidence: `crates/terminus/src/lib.rs:11`, `crates/terminus/src/lib.rs:69-81`, `crates/terminus/src/cmd/reindex.rs:100`, `crates/terminus/src/cmd/ingest.rs:53-63`, `crates/terminus/src/cmd/backfill.rs:342`, `crates/terminus/src/cmd/read.rs:319`; `cargo clippy --explain print_stderr` on clippy 0.1.99.
- D-04 (`--json` failures): Every `--json` command writes a document with `ok: false` and the reason on every operational failure, not only the five the roadmap names, and the "Most operational failures write no document" list in `json-shapes.md` is removed. Misuse (exit 2) still writes no document, because every misuse is raised in a `parse` fn before the output mode is known. John chose every command, which is OUT-02's wording. Evidence: `.planning/REQUIREMENTS.md` (OUT-02), `docs/json-shapes.md:52-72`, `crates/terminus/tests/cli.rs:494` (`misuse_exits_two_with_an_empty_stdout`).
- D-05 (`--json` failures): The document `main` writes is the command's own empty document, the one each command builds for the no-store answer, with `ok: false` and the reason, never a generic `data: {}`. Where the empty document depends on the arguments (replay's thresholds, `observations regenerate`'s `since`, export's destination) it is built from the parsed args before `run` consumes them. Evidence: `crates/terminus/src/lib.rs:105-109,232-235`, `crates/terminus/src/cmd/replay.rs:31`, `crates/terminus/src/cmd/observations.rs:137`, `crates/terminus/src/cmd/export.rs:74`, `crates/terminus/src/cmd/json.rs:1-20`.
- D-06 (`--json` failures): Under `--json`, `main` writes only the document and no `terminus: <reason>` line on stderr. `Failure::Silent` keeps meaning the command already wrote its account, for documents that carry real data (verify with failures, reindex with skipped sessions, doctor with problems). No command writes a document and then returns `Failure::Operational`. Evidence: `crates/terminus/src/cmd/read.rs:428-443`, `crates/terminus/src/cmd/verify.rs:29-57`, `crates/terminus/src/cmd/reindex.rs:57-116`, `crates/terminus/src/cmd/doctor.rs:169-199`, `docs/json-shapes.md:78-92`.
- D-07 (Sizes): `cmd::human`, in powers of two (KiB, MiB, GiB, one decimal), is the only byte formatter. `backfill::bytes` (powers of ten, with a comment that wrongly says it matches `du`), `status.rs`'s `human` and `uninstall.rs`'s `human` are deleted, and the install estimate prints GiB. Rejected: powers of ten everywhere, which changes status, compact, usage, export and uninstall. Evidence: `crates/terminus/src/cmd/mod.rs:133-167`, `crates/terminus/src/cmd/backfill.rs:194-215`, `crates/terminus/src/cmd/status.rs:166-203`, `crates/terminus/src/cmd/uninstall.rs:536-549`.
- D-08 (Prompt line): A turn the prompt line shows only as `...` is not recorded as injected, in the session state or in `decision.injected`, matching `brief::quoted`, so a later prompt can still quote it. The recorded turns are computed after `render`. John chose this over keeping today's record, which blocks a turn the model never saw. Evidence: `crates/terminus-core/src/inject/prompt.rs:456-499`, `crates/terminus-core/src/inject/prompt.rs:296-308`, `crates/terminus-core/src/inject/brief.rs:270-286`, #94 ("the way the brief now does").

## Decisions

- D-09 (Escaping): `doctor`'s human report (`write_out`) goes through the escaping path, applied to the rendered report and never to `Check.finding`, which also feeds `doctor --json`. The 200-byte cut at `doctor.rs:866` stays ahead of the escape. `show` escapes its header and window lines through the helper and writes the body raw. `mcp::serve` is left alone. Evidence: `crates/terminus/src/cmd/doctor.rs:848-873`, `crates/terminus/src/cmd/doctor.rs:1271-1281`, `crates/terminus/src/cmd/show.rs:105`, `crates/terminus/src/cmd/mcp/mod.rs:113`.
- D-10 (Escaping): The per-field `escape::controls` calls in `search.rs:129-134`, `show.rs:110-174` and `observations.rs:245-271` come out; `escape::controls` stays the one primitive. The `escape.rs` module doc, `THREAT-MODEL.md:128` and `docs/commands.md:63,76,94` are rewritten to say every command's human output escapes. Evidence: `crates/terminus/src/escape.rs`, `THREAT-MODEL.md`, `docs/commands.md`, `crates/terminus/tests/recall_cli.rs:1633`, `crates/terminus/tests/observations.rs:585`.
- D-11 (`--json` failures): compact's held-lock answer keeps its measured, unchanged `before` and `after` footprint rather than the zeroed empty document. Evidence: `crates/terminus/src/cmd/compact.rs:52-71`, `docs/json-shapes.md:500-506`.
- D-12 (`--json` failures): `read::unusable` is deleted. The damaged-log path in stats and replay returns an operational failure carrying `read::damaged(..)`, and the document it produces is byte-identical to today's: the empty document, `ok: false`, `labels: []`. Evidence: `crates/terminus/src/cmd/read.rs:428-443`, `crates/terminus/src/cmd/stats.rs:33-41`, `crates/terminus/src/cmd/replay.rs:41-46`, `docs/json-shapes.md:345`.
- D-13 (Helpers): One duration formatter prints `Ns`, `Nm Ns` or `Nh Nm` from whole seconds. "under a second" (backfill, zero) and "(no duration)" (observations, `None`) stay with their callers, so a 0-second session in `observations` still prints `0s`. Evidence: `crates/terminus/src/cmd/backfill.rs:217-230`, `crates/terminus/src/cmd/observations.rs:310-318,438-444`, `crates/terminus/tests/observations.rs:414`.
- D-14 (Helpers): One `Failure`-to-text function on `Failure` in `cmd/mod.rs` replaces the four matches at `doctor.rs:1216`, `install/mod.rs:383`, `uninstall.rs:551` and `mcp/tools.rs:586`; #107's fifth, a second match in `tools.rs`, was removed by f299719. `CLAUDE_DEFAULT_CLEANUP_DAYS` and `KEEP_CLEANUP_DAYS` get one definition that doctor and install both read; `LOW_CLEANUP_DAYS` stays doctor's. Evidence: `crates/terminus/src/cmd/doctor.rs:73-81,1216-1221`, `crates/terminus/src/cmd/install/mod.rs:34-39,383-388`, `crates/terminus/src/cmd/uninstall.rs:551-556`, `crates/terminus/src/cmd/mcp/tools.rs:576-591`.
- D-15 (Purge): `uninstall --purge` measures every file under the data directory recursively, the rule `data.rs`'s `bytes` uses for `data move`, so `snapshots/`, `decisions/` and `LOCK` count, both in the size shown before the question and in the `deleted N byte(s)` line. `status`'s `size_bytes` stays the three-file store size. The early return with no `terminus.db` is unchanged. John chose everything in the directory over the store files plus `snapshots/`. Evidence: `crates/terminus/src/cmd/uninstall.rs:440-487,512-534`, `crates/terminus/src/cmd/data.rs:510-528`, `crates/terminus/tests/uninstall.rs:202-209,786-822`, `docs/commands.md:219`, `docs/install.md:91`.
- D-16 (Prompt line): The fix lives in `inject/prompt.rs`'s `render`; `inject::clip` is not touched, because the brief, the frame backstop and the decision record share it. Evidence: `crates/terminus-core/src/inject/mod.rs:174-191,466`, `crates/terminus-core/src/inject/prompt.rs:272-310`.
- D-17 (Prompt line): A hit whose text is longer than its share, with a share no larger than `chars(ELISION)`, renders as `...` alone, a share of 0 included, following the brief's `cut` rule. A hit whose whole text fits its share prints as it is. `render` counts the mark into the fixed cost of every line it cuts to the mark, so a mark never overspends its share. The backstop cuts the last turn line, not a harmless tail as in the brief, so leaving the overspend to it would cut a turn id. John chose this after the plan review found it. When even the ids, dates and marks are over, `render` leaves out the last turn and shares again, so no turn line reaches `frame`'s backstop. John chose this at verify. Evidence: `crates/terminus-core/src/inject/brief.rs:243-258,395-410`, `crates/terminus-core/src/inject/prompt.rs:283-294`, `crates/terminus-core/tests/inject_prompt.rs:798-833`.
- D-18 (Comments): New comments and tests cite only #72, #107, #95 and #94, never a requirement id or a decision tag, and comments are rewrapped by hand with no `cargo fmt` over the workspace. Evidence: `crates/terminus-core/tests/planning_tags.rs`, `.planning/phases/7/CONTEXT.md` (D-17).

## Acceptance criteria

- [ ] AC1: With ESC and BEL archived in a session key, a project path, a branch, and a run's notes and error, the human output of `sessions`, `usage`, `retention`, `reindex`, `verify`, `status`, `doctor`, `ingest`, `backfill`, `search`, `show` and `observations` holds no 0x1b or 0x07 byte on stdout or stderr and shows `\u001b` and `\u0007` where they were, while the `--json` output of those commands, the hook document and `show <id>`'s record body hold the archived bytes unchanged.
- [ ] AC2: A `println!` or `eprintln!` added in `crates/terminus/src` outside the output helpers fails `cargo clippy`, and `escape::controls` is no longer called from `search`, `show` or `observations`.
- [ ] AC3: Each `--json` command, made to fail operationally (for example with an unreadable data directory), prints exactly one JSON document with `ok: false`, the reason, and the empty-document fields `docs/json-shapes.md` lists for it, and writes nothing on stderr; misuse still exits 2 with an empty stdout; `read::unusable` no longer exists.
- [ ] AC4: The install estimate and `status` format sizes through one formatter, so 1,400,000,000 bytes prints as `1.3 GiB` in both, and no command prints `GB` or `MB`.
- [ ] AC5: On a data directory holding `snapshots/` and `decisions/`, the size `uninstall --purge` shows before it asks equals the sum of every file under the directory, and its `deleted N byte(s)` line prints the same N.
- [ ] AC6: A prompt-line hit given a share of 0 to 3 characters, whose text is longer than its share, shows as `...`, or is left out when the budget cannot hold its mark with every line whole; either way that turn is not recorded as injected in the session state or in `decision.injected`, so a later prompt can quote it; the brief's output is unchanged.
- [ ] AC7: `THREAT-MODEL.md` no longer names #72 as open, `docs/json-shapes.md` holds no list of operational failures that write no document, and `docs/commands.md` and `docs/install.md` say the purge size counts everything `--purge` deletes.
